# movie-rating-system

This project focuses on creating a movie rating system to log users' reviews and ratings of movies they watch.
We will be using a provided movie database that comes with ratings and users.
The database can be found here: https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset/data
